# BloggerSpot

블로그스팟 설정·네이버 서치어드바이저 수집을 위한 Windows 프로그램입니다.

## 다운로드

최신 버전 zip:

https://github.com/lee3215-ko/blogspot-app/releases/latest/download/BloggerSpot.zip

1. zip을 받습니다.
2. 폴더를 풉니다.
3. `BloggerSpot.exe`를 실행합니다.

이미 쓰는 폴더가 있으면 `data` 폴더는 그대로 두고 나머지 파일만 덮어쓰면 됩니다. 프로그램이 켜져 있을 때 새 버전이 있으면 자동 업데이트 창이 뜹니다.
